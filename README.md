# Goofish search (goofish)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `goofish`. It searches second-hand listings on Goofish without logging in and returns the price, the original price, condition and brand tags, the region, how many people want the item, the posting date, the seller and the link; it can also watch a keyword, after which each check takes only a few seconds and marks new listings that have not been seen before.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `action` | `search` (default) searches with a headless browser and takes 10–40 seconds; `monitor-init` opens the browser once to set up a watch for the keyword; `monitor-query` checks a watch in a few seconds without opening a browser, and marks newly appeared listings with 🆕 and puts them first; `monitor-list` and `monitor-remove` show and remove watches; `doctor` runs a self-check |
| `keyword` | The keyword to search for. It is required for every action except `monitor-list` and `doctor` |
| `pages` | For `search` only: the number of pages to fetch, 1–5, with 30 listings per page; each extra page adds about 10 seconds. The default is 1 |
| `sort` | `default` (Goofish's order), `price_asc`, `price_desc`, `newest`, `most_wanted` |
| `min_price`, `max_price` | The price range, in yuan |
| `limit` | The maximum number of listings to show, 1–150, default 30 |
| `format` | `md` (default) or `json` (for code inside `miyu call`) |

Sorting and price filtering apply only to the pages that were fetched, not to every listing on the site: if you want more complete results, increase `pages`. Ad slots have already been removed from the results.

## Dependencies

The tool needs Python 3.8+, [playwright](https://playwright.dev/python/) and a Chromium-based browser. You can use:

```sh
pip install --user playwright          # Arch: pacman -S python-playwright
python3 -m playwright install chromium  # or install the system Chromium / Chrome / Edge; the script finds it itself
```

Once they are installed, have the AI call `action=doctor` once; it actually starts a headless browser to verify the setup.

## Sandbox and storage

This section explains where the tool stores its data and how it runs inside Miyu's sandbox.

- Watches are saved in the state folder that Miyu gives the script, `MIYU_STATE_DIR`: they are kept separately for each Miyu account and survive a restart.
- The cache folder `MIYU_CACHE_DIR` holds things that can be thrown away: browser session snapshots (reused for up to 25 minutes to trigger the risk controls less often) and the browser's own profile folder (`browser-home/`). The script does not write anywhere else.
- Miyu's sandbox replaces `~/.config/chromium` and `~/.config/google-chrome` with empty read-only folders, and `/dev/shm` cannot be written either; so the script sets a separate `XDG_CONFIG_HOME` for the browser, adds `--disable-dev-shm-usage`, and on Linux also adds `--no-sandbox` (because Chromium's own sandbox cannot run inside Miyu's sandbox). On Linux, both Landlock and bubblewrap mounts have been tested and work. macOS and Windows have not been tested yet.
- The cache folder is inside the system temporary folder and is cleared on a restart: losing the session snapshot only means it is rebuilt next time, and watches are not affected.

## Risk controls

This section explains what the tool does when Goofish blocks a request.

Goofish blocks requests from time to time (RGV587, with the message `被挤爆啦`); the script retries on its own for up to about 40 seconds, and if that still fails it reports an error, in which case wait about 3 minutes and try again. A watch works by resending the request from the time the watch was set up exactly as it was, so once the session expires the request is refused, and the error tells you to run `monitor-init` again.
